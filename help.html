AlbumEasy Designer — Help Guide

A visual editor for designing AlbumEasy stamp album pages. Design in the browser, download a .txt file, and generate your PDF with the AlbumEasy CLI.

Workflow

  1. Open the designer in your browser
  2. Set page format, margins, title, borders, etc.
  3. Add stamps, rules, images, and text blocks
  4. Arrange elements by dragging (they snap to the grid)
  5. Click Download .txt to export
  6. Run ./AlbumEasy -c album.txt to generate the PDF

Page Settings

Collapsible panel on the right side. Key sections:

Paper & Margins

  • Paper format — A4, US Letter, Scott, Minkus, Davo, Stanley Gibbons. Sets page size and default margins.
  • Margins — Left / Right / Top / Bottom in mm. The title is always drawn at the top margin (below the border).

Borders

  • Three nested border lines (outer, inner 1, inner 2) with a gap between each. Set thickness to 0 to disable a line.

Title & Spacing

  • Title text / size — Centre-aligned, drawn below the border.
  • Space after title (mm) — Gap between the title and where content flow begins. The blue dashed line in the canvas shows this boundary. Elements cannot be placed above it.

Grid & Crop

  • Snap grid size — Elements snap to this grid when dragged (default 2 mm). Set below 0.5 to disable.
  • Page quadrille — Stamp-album grid lines (like a Scott/Minkus page). Configurable cell size and border.
  • Crop marks — Corner marks for trimming oversized paper.

Footer Extras

  • Page number — Position, start number, before/after text. Supports $PAGES$ placeholder for total count.
  • Date — Auto-inserts the generation date. Format, separator, and surrounding text configurable.

Colours

Seven colour fields (page text, border, title, footer, header, stamp text, stamp border). Only emitted in the .txt if not black. Use the datalist for common names or type any CSS colour.

Custom Fonts

Add (ID, font name) pairs. The ID (2–12 chars, no spaces) is used in stamp/text font fields. Emits ALBUM_DEFINE_FONT commands.

Adding Elements

Stamps

  • Drag to position. Snaps to grid on release.
  • Properties: X, Y, Width, Height, Shape (rect/oval/diamond/hexagon/octagon), Font, Font size, Border thickness, Border style, Inside text, Text offset, Below left/centre/right text.
  • In column mode, the column is determined by X position (left of divider = left column, right = right column).

Rules

  • Horizontal lines at a specific Y. Drag vertically to move.
  • Properties: Y, Thickness, Left pad, Right pad, Column (left/right in 2-col mode).

Image Stamps

  • Double-click to open the file picker (preview shown on canvas).
  • Properties: Y, Width, Height, File path, Frame on/off, Below left/centre/right text.
  • X is cosmetic only — on export, images are centred in their row at the specified Y.

Text Blocks

  • Drag vertically to position. The yellow dashed box sizes to fit the text (not full width).
  • Properties: Y, Column (Full page / Left / Right), Font, Font size, Alignment, Padding, Vspace after, Paragraph mode, Text content.
  • Use \n for line breaks.
  • Paragraph mode emits PAGE_TEXT_PARAGRAPH_START/END for multi-line flowing text.
Column mode limitation: In two-column mode, text and rules use flow-based positioning (PAGE_VSPACE). They appear sequentially after the last stamp in that column, not at an absolute Y. For text that must appear at a specific position, set Column to "Full page" and use Alignment to position it visually.

Two-Column Mode

  • Toggle in Page Settings. Blue tint = left column, red tint = right column.
  • Column divider (%) and gap (mm) control the split.
  • Stamps: assigned to a column by their X position relative to the divider.
  • Rules & Text: use the Column dropdown in their properties.
  • Exports PAGE_COLUMN_START / PAGE_COLUMN_NEXT / PAGE_COLUMN_STOP.

Undo / Redo & Save / Load

  • Ctrl+Z — Undo (up to 50 steps)
  • Ctrl+Y or Ctrl+Shift+Z — Redo
  • Save .json — Downloads a project file with all pages, elements, and settings.
  • Load .json — Restores a saved project (pushes current state to undo history).

Every action (add, delete, drag, property change, page setting change) creates an undo checkpoint.

Exporting

Click Download .txt. The generated file contains:

  1. Header comments (generator, timestamp)
  2. Album-level settings (size, margins, border, title, colours, fonts, etc.)
  3. One section per page with PAGE_START / PAGE_START_INFO
  4. All elements in Y-sorted order

Feed it to AlbumEasy: ./AlbumEasy -c album.txt

Info Pages

Tick the "Info page" checkbox in the toolbar to mark the current page as informational (suppresses title, border, header, footer). "In count" includes it in the page number sequence.

Tips & Gotchas

Title position: The title is always at the top margin, below the border. You can't move it independently. To get it closer to the top, reduce the top margin. To push content down without moving the title, increase "Space after title".
Blue dashed line: This is the content floor. No element can be placed above it. It moves when you change the title font size or "Space after title". The faint red zone above it is the blocked area.
Image files: The file picker is for preview only. The exported .txt uses the file path you type in the "Path" field. Make sure the file exists relative to where you run AlbumEasy.
Grid snapping: If elements feel "stuck", check your snap grid size. A 2 mm grid means elements only move in 2 mm increments. Set to 0.5 for finer control.
Multiple pages: Use the page number input (top right) to jump between pages, or click "+ Page" to create the next one. Each page has its own elements — they don't overlap.
