A small partial blurb from the Album Easy website
AlbumEasy came about because I was looking for an easy way of creating custom stamp album pages for my own use.
Initially, I experimented with general-purpose software packages as a means of creating album pages, drawing programs, word-processors, spreadsheets etc. Although I had some success, the amount of time and effort did not seem to justify the end result and I felt that there had to be a better way.
After some thought, I came up with the idea for AlbumEasy, a dedicated program for creating stamp album pages. AlbumEasy generates ready to print PDF pages from a text file containing commands that describe the pages.
